# PDP仕様メモ

## PDPの初期化(PLPから遷移する場合)

### PLPの各 `item`の中で、以下のデータはそのまま利用できるため、そのまま使う
|  項目  |  JSONの値  |
| ---- | ---- |
|  画面トップの画像  |   `item.images`  |
|  ブランド名  |   `item.product.brand.name`  |
|  フォローブランド  |   `item.product.brand.id`  |
|  品名  |   `item.product.name`  |
|  Gilt価格  |   `skus.salePriceのmin 〜 max`  |
|  メーカー小売価格  |   `skus.msrpPriceのmin 〜 max`  |

カラーバリエーションが1つしか無いので、まずそれを表示する。
その後、`looks_details` で残りのカラーバリエーションを取得してappend -> view を更新する流れ。

PLPで複数のカラーバリエーションを持っている商品が出る場合、
PLPで表示されている色が、PDPの初期表示になる。

`skus` の先頭ではない。

### looks_detailsで必要な情報

- `looksId` に紐づいている、商品一覧
 - カラーバリエーション
 - サイズ一覧
 - 売り切れ

## カラバリとサイズ、SKUの関係

選択した商品は複数のSKUから構成される。`item.skus`がそれ。SKUを特定する流れは、バリエーション(色)→サイズの順。

検証環境のデータにおいて、商品がskuを持っていないケースがあった。
`item==sku` が成り立つ場合、JSONの `item.skus` が `[]` になる。

## カート or ウェイトリストに送信する

ウェイトリストやカートにデータを入れる場合、必要なのは、`saleId` と `sku.id` になる。
その商品に `skus` がない場合は、`item.id` になる。
HOMEによくある。ディフューザーとか。

ログイン状況、ウェイトリスト追加可否によって、以下のように表示が異なる。

| 状況 |  ForSale  |  SoldOut  |  Reserved  |
| ---- | ---- | ---- | ---- |
| ゲスト |  A（カートに追加）  |  A（ウェイトリストに追加）  | A（ウェイトリストに追加）  |
| ユーザー |  C  | B |  B  |

- A: ログイン必須
- B: ウェイトリストOKならウェイトリストへ追加ボタン、NGの場合はウェイトリストに追加できませんボタン表示。
- C: カートへ追加

## テストケース

### 初期表示

- 写真が表示されること
- ブランド名と、フォローブランドボタンが出ること
    - フォローブランドボタンは、`isInternal == false` の場合だけ
    - フォローしているブランドの場合は、♥で表示されること
- 商品名が表示されること
- 商品名の隣に、共有ボタンが表示されること
    - 共有ボタンを押すと、URLと読み込んだ画像を元にOSの共有機能に連携すること
- カラーリストが表示されること
    - PLPのアイテムで指定された `giltColor` が初期選択されていること
    - 全てのサイズが売り切れの場合、斜め線が入っていること
- 複数サイズ展開の場合、サイズリストが表示されること
    - 売り切れサイズの場合、斜め線が入っていること
- 商品がある場合、残りN点の表記が表示されること
- 売り切れの場合、売り切れと表示されること
- 取り置きの場合、取置されている旨が表示されること
- ウェイトリストに追加できる場合、ウェイトリストの説明が出ること
- ウェイトリストに追加できない場合、ウェイトリストに追加できない説明が出ること
- サイズが有る商品の場合、サイズ表を見るが表示されること
    - サイズ表を見ると押すと、サイズ表示ページが表示されること
- 返品についての説明が出ること
- スタイル情報についての説明が出ること
- ブランド情報についての説明が出ること
- 正規ブランド保証の説明が出ること

###　ボタンの表示内容について

- ゲストの場合
    - 販売中以外 and ウェイトリスト追加NG の場合、ウェイトリストに追加できないボタンになる
    - 販売中以外 and ウェイトリスト追加OK の場合、ウェイトリストに追加（要ログイン）ボタンになる
    - それ以外のセール中の場合、カートに追加（要ログイン）ボタンになる
- メンバーの場合
    - 販売中以外 and ウェイトリスト追加NG の場合、ウェイトリストに追加できないボタンになる
    - 販売中以外 and ウェイトリスト追加OK の場合、ウェイトリストに追加ボタンになる
    - それ以外のセール中の場合、カートに追加ボタンになる

### カラーとサイズの連動について

- カラーが変更された場合
    - サイズの一覧が変わる。サイズがない場合は何も表示されなくなる
    - 選択したサイズによって、下部のボタンの表示が変わる（カートに追加 or ウェイトリスト)
- サイズが変更された場合
    - 在庫のあるなしに応じて、下部のボタンの表示が変わること

### 写真の連動について

- PDPの写真を変更すると、拡大画像の選択画像も変わる
- 拡大画像の写真を変更したら、PDPの写真も変更される
- 拡大画像画面で色を変えると、PDPのカラーも変更される

### カートに追加

- 選択したSKUがカートに追加されること

### ウェイトリストに追加

- 選択したSKUがマイページ→ウェイトリストに表示されること
